Site 3D et SEO : risques et bonnes pratiques

La 3D n’empêche pas d’être bien référencé, mais elle crée des risques précis. Voici lesquels, et comment les éviter.

Sommaire

Ce que Google voit d’un site 3D

Une scène 3D est, pour Google, une image animée : il n’en lit pas le contenu. Ce qui se référence, ce sont le titre de la page, les textes, les images avec leur description, la structure des titres et la vitesse d’affichage. Un site 3D se positionne donc grâce à tout ce qui entoure la scène.

La 3D n’est pas un handicap en soi. Le problème apparaît quand elle remplace le texte ou ralentit la page.

Les trois risques principaux

  • La vitesse. Une scène lourde retarde l’affichage. Google mesure l’expérience réelle des visiteurs avec les Core Web Vitals : un plus gros élément affiché en 2,5 secondes ou moins (LCP), une réponse en 200 millisecondes ou moins (INP), une mise en page stable (CLS de 0,1 ou moins) ;
  • L’absence de texte. Si les titres et les descriptions sont dessinés dans la scène, la page n’a rien à indexer ;
  • Le mobile. Une scène pensée pour grand écran peut être lente ou inutilisable sur téléphone, alors que Google évalue d’abord la version mobile.

Six bonnes pratiques

  1. Garder le texte en HTML : titres, paragraphes, questions fréquentes, boutons ;
  2. Charger la 3D après le premier affichage : la page est lisible tout de suite, la scène arrive ensuite ;
  3. Prévoir une image de repli aux dimensions fixes, avec une description pour les lecteurs d’écran ;
  4. Alléger les modèles : formats web compressés, textures raisonnables ;
  5. Respecter « réduire les animations » pour les visiteurs qui le demandent ;
  6. Créer une page dédiée à l’offre, comme notre page création de site internet 3D en Suisse, pour répondre clairement à la requête.

Ce que nous appliquons nous-mêmes

Le cube de la page d’accueil de Websituation applique ces principes : le texte de l’accueil est du HTML indépendant du cube, la 3D utilise les transformations du navigateur sans bibliothèque ni canvas, et les animations se désactivent si le visiteur le demande. Les mesures sont détaillées dans l’étude de cas du cube 3D : performance mobile de 97 sur 100 en laboratoire.

Ce cube reste un objet simple. Pour des scènes plus riches, les mêmes règles s’appliquent, avec une attention plus grande au poids des modèles et au chargement différé.

Comment vérifier votre site

Testez vos pages sur mobile avec PageSpeed Insights, puis surveillez dans la Search Console les pages indexées et les Core Web Vitals. Comparez la page avec et sans la scène : si le texte et les images de repli suffisent à expliquer l’offre, la base est saine.

À retenir
  • Google ne lit pas la scène 3D : le texte et la vitesse font le référencement.
  • Trois risques : une page lente, un texte absent, un mobile oublié.
  • Texte en HTML, 3D en différé, image de repli et modèles allégés suffisent à éviter l’essentiel.

FAQ

Google indexe-t-il une scène 3D ?

Il ne lit pas le contenu de la scène. Il indexe le texte et les images de la page qui l’entoure.

Quel est le principal risque SEO d’un site 3D ?

La lenteur : une scène lourde dégrade la vitesse d’affichage, surtout sur mobile.

Faut-il une page dédiée à la 3D ?

Oui, une page claire qui explique l’offre, avec du texte, une FAQ et des liens vers vos autres services.
